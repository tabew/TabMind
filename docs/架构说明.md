# 架构说明

## 一、分层

| 层 | 位置 | 职责 | 依赖方向 |
|---|---|---|---|
| 入口 | `src/core/main.cpp` | 初始化、创建窗口、进入消息循环 | → UI |
| UI | `src/ui/ui_window.cpp` | Win32 窗口、配置表单、日志面板、启停按钮 | → Config、MessageHandler |
| 消息编排 | `src/message/message_handler.cpp` | 事件解析、@门禁、插件派发、AI 触发判定、群/私聊分流 | → Plugin、AI、Config |
| AI | `src/ai/ai_client.cpp` | 大模型请求、上下文记忆、图片多模态、错峰重试 | → simple_http / simple_json |
| 协议 | `src/core/bot_client.cpp` | OneBot v11 正向 WebSocket，事件回调 | → simple_ws |
| 插件框架 | `src/plugin/plugin_manager.cpp` | DLL 扫描/加载/卸载、消息派发、AI 回复钩子 | ← 插件（DLL） |
| 基础库 | `include/simple_json.hpp`、`simple_http.hpp`、`simple_ws.hpp` | JSON 解析、WinHTTP 封装、Winsock WebSocket | 无（系统 API） |

依赖是单向的：UI 不反向依赖业务实现，插件通过纯虚接口与宿主解耦。

## 二、一条消息的完整流程

```
OneBot 协议端 (NapCat)
        │  WebSocket 事件 JSON
        ▼
  bot_client          解析事件 → 回调 MessageHandler
        │
        ▼
  message_handler
   ├─ 忽略机器人自己发的消息
   ├─ 解析 sender_name（群名片 > 昵称 > QQ 号）
   ├─ 抽取纯文本 + 判断是否 @机器人 + 下载图片到本地
   ├─ 去掉触发前缀（/chat、/ai、你好 …）→ plain_text
   ├─ 收集被 @ 的 QQ 列表
   │
   ├─ 构造 PluginContext → 派发插件
   │     ├─ 群聊@门禁开启且本条未@且无前缀：
   │     │     只派发给「免@白名单」插件
   │     └─ 否则：派发全部插件
   │     └─ 任一插件返回 true → 结束（不调用 AI，省 Token）
   │
   ├─ 私聊：处理 /reset 等记忆指令 → 构造提示 → 必定回复
   └─ 群聊：
         ├─ @了机器人 或 命中前缀 → 必定回复
         ├─ 必须@模式且未@ → 只写入记忆，不回复
         └─ 宽松模式 → 冷却时间检查 + 允许模型自主沉默（[SILENT]）
        │
        ▼
   AI 线程（异步）
   ├─ 组装上下文（历史轮数、长期记忆、图片）
   ├─ 调用模型（stream / 非 stream）
   ├─ 解析回复，必要时触发记忆压缩
   └─ 回调 dispatch_ai_reply 钩子（插件可改写/追加表情）
        │
        ▼
   发送：按 "//" 拆分为 1~2 条短消息，支持 [REPLY] 引用回复
```

## 三、关键设计

### 1. 插件派发与 @ 门禁

群聊默认「必须 @ 或命中前缀才响应」，防止机器人在群里被动刷屏。
门禁实现在**插件派发层**而非 AI 层：未 @ 时只把消息交给白名单插件（如随机图/随机老婆），其余插件收不到，AI 也不回应。

白名单按 `DLL 文件名 + 插件名 + 描述` 做小写子串匹配，可在界面里编辑。

### 2. 插件 ABI

- 通过 `IBotPlugin` 纯虚接口交互，宿主 `LoadLibrary` 后取 `create_plugin` / `destroy_plugin`
- `PluginContext` 新增字段一律**追加到末尾**，保持旧插件二进制兼容
- 同步回调（`std::function`）与异步回调（C 函数指针）分离：后台线程只能用后者

### 3. 零依赖基础库

| 文件 | 替代 | 说明 |
|---|---|---|
| `simple_json.hpp` | nlohmann/json | 内置最小实现，并提供 `namespace nlohmann` 兼容别名 |
| `simple_http.hpp` | cpp-httplib | 基于 WinHTTP，支持 HTTPS 与超时 |
| `simple_ws.hpp` | ixwebsocket | 基于 Winsock，仅实现 OneBot 所需的文本帧 |

这样整个项目只需要 Windows SDK，编译产物体积小、部署无运行时依赖（`/MT` 静态链接 CRT）。

### 4. 记忆

- 短期：按 `context_id`（`private_<QQ>` / `group_<群号>`）保存最近 N 轮
- 长期：超过阈值后异步压缩成摘要文本，落盘到 `data/` 下，下次会话注入

## 四、扩展点

| 需求 | 做法 |
|---|---|
| 新增指令 | 写插件实现 `on_message`，返回 `true` 拦截 |
| 改写 AI 回复 | 插件实现 `on_ai_reply`，修改传入的 `std::string&` |
| 新增 AI 供应商 | 在 `ai_client` 内扩展 `auth_style` 与请求体组装 |
| 更换协议端 | 只需兼容 OneBot v11 正向 WebSocket，改 `onebot.ws_url` 即可 |
